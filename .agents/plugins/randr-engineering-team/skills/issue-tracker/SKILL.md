# Issue Tracker

Search open issues before creating one. A defect issue must include environment, commit SHA, exact reproduction steps, expected and actual result, severity, and links to Playwright traces/screenshots or manual evidence. Keep separate root causes separate; link related work rather than duplicating it.

Create issues only after the owner or orchestrator accepts the finding as real. Never create issues for flaky, unreproduced, or sensitive evidence without redacting it first.
